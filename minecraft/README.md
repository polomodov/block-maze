# Изумрудный лабиринт для Minecraft Bedrock

Прототип add-on по мотивам «Храма изумруда». Скрипт строит в небе над игроком случайный лабиринт. Нужно собрать изумрудные плитки и встать на золотой блок. В среднем и большом лабиринте бродят кадавры (husk): если поймают, игрок возвращается на старт и теряет одну из трёх жизней. Урона нет, вещи не выпадают. После игры игрок возвращается туда, откуда начал, с прежним режимом игры, а лабиринт исчезает. Лучшее время для каждого размера сохраняется в мире.

## Как поиграть

1. Скачайте `EmeraldMaze.mcaddon` из релиза или соберите его сами (см. ниже) и откройте файл: Minecraft импортирует пак.
2. В настройках мира включите пак в «Наборах параметров поведения». Экспериментальные функции не нужны: аддон использует только стабильный Script API.
3. В игре напишите `/maze:start`. Откроется меню размеров. Можно сразу указать размер: `/maze:start small`, `medium` или `large`. Выйти раньше: `/maze:stop`.

Для старта нужен свободный участок неба над игроком. Если там есть блоки или арена другого игрока, перейдите в другое место. Повторный старт завершает текущую партию и возвращает игрока к исходной точке перед постройкой новой арены.

При обновлении с первого прототипа игрок с прежним сохранением вернётся на место старта в своём режиме. Старые сохранения не содержат данных о владельце арены и мобов, поэтому такие оставшиеся лабиринты убираются вручную.

Нужна версия Minecraft Bedrock не ниже 1.26.50. Чтобы монстры появились, сложность мира должна быть выше «Мирной».

## Разработка

```
cd minecraft
npm install
npm test             # тесты генератора, игровых сессий и упаковки
npm run typecheck    # проверка типов против @minecraft/server
npm run package      # dist/EmeraldMaze.mcaddon
npm run deploy:local # Windows: копирует пак в development_behavior_packs
```

После `deploy:local` включите пак в тестовом мире. Дальше после каждой правки запускайте `npm run deploy:local` и пишите в чате игры `/reload`, перезапуск мира не нужен. Путь к папке паков можно задать переменной `MC_DEV_BP`.

- `src/maze.ts` содержит чистую логику без зависимостей от игры: генератор (backtracker с seed), раскладку изумрудов, монстров и финиша. Её проверяют тесты в `tests/`.
- `src/main.ts` отвечает за всё, что связано с игрой: постройку, команды, меню, игровой цикл, рекорды.
- `pack/` содержит `manifest.json` и иконку пака.
